# Análisis de arquetipos aplicado a estrellas RR Lyrae

Repositorio correspondiente a una tesis de Magíster en Ciencia de Datos sobre la aplicación de análisis de arquetipos a curvas de luz de estrellas RR Lyrae provenientes de OGLE-III y OGLE-IV.

El proyecto estudia la capacidad del análisis de arquetipos para identificar patrones morfológicos representativos, estables e interpretables, y analiza su relación con los subtipos RRab, RRc y RRd. K-means se utiliza como modelo de referencia.

## Estado del proyecto

Proyecto en desarrollo. La redacción de la documentación y las instrucciones completas de reproducción se encuentran en curso.

## Estructura

- `notebooks/`: preparación de datos, experimentos, evaluación e interpretación.
- `src/`: funciones y módulos utilizados por los experimentos.
- `data/README.md`: información sobre los datos utilizados.
- `requirements.txt`: dependencias del entorno de Python.

## Entorno

El proyecto fue desarrollado con Python 3.12.6.

```bash
python -m venv venv-tesis2
source venv-tesis2/Scripts/activate
python -m pip install -r requirements.txt

```
